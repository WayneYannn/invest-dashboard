# 债基穿透字段识别参考

## 字段清单与截图定位

| 字段 | JSON键 | 类型 | 截图位置 | 识别要点 |
|---|---|---|---|---|
| 基金代码 | (键名) | string | 页面标题/URL | 6位数字，如 `400030` |
| 基金名称 | name | string | 页面标题 | 去掉"债券""基金"后缀，如"东方添益" |
| 久期类型 | duration | enum | 季报"久期"栏 | <2年→short, 2-5年→mid, >5年→long |
| 信用等级 | credit | enum | 持仓评级分布 | 利率债为主→rate, 中高等级→mid, 含低评级→low |
| 利率债占比 | rate_ratio | number | 资产分类表 | 国债+国开+农发+口行等政策性金融债，百分比数字 |
| 信用债占比 | credit_ratio | number | 资产分类表 | 企业债+中票+短融，百分比数字 |
| AA+及以上占比 | aa_plus_ratio | number | 评级分布表 | AAA+AA+占信用债的比例，百分比数字 |
| 规模 | scale | number | 基金概况 | 单位转成"亿"，如"200亿" |
| 杠杆率 | leverage | number | 季报"杠杆比例" | 倍数，如1.1 |
| 前五大重仓 | top5 | array | 前五大持仓表 | 债券简称，取前5个 |
| 季报日期 | report_date | string | 季报标题 | 如 `2026Q2`、`2025Q4` |

## 信用等级判读规则

- `rate`（利率债为主）：利率债占比 ≥70%，或持仓全是国债/国开/农发/口行
- `mid`（中高等级信用）：信用债占比 20-70%，且 AA+及以上 ≥70%
- `low`（含低评级）：AA+以下占比 >30%，或含 AA-/高收益债

## 久期判读规则

季报披露的"加权平均久期"或区间：
- `<2` → `short`
- `2-5` → `mid`
- `>5` → `long`

若季报只给区间不给数值，取中点。若无久期数据，按"重仓债券平均剩余期限"估算。

## 常见截图来源

1. **天天基金**：基金详情页 → 持仓明细 + 季报
2. **基金公司官网**：定期报告 PDF
3. **Wind/Choice**：终端截图（字段最全）

## 合并策略

- 用户提供的单只基金数据，合并进已有 bonds.json（保留其他基金）
- 若用户没提供已有 bonds.json，则生成只含当前基金的新文件
- `updated_at` 用当前时间（北京时间 ISO 格式）
